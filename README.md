# 💻Shadertoy-GLSL-shaders

Here are the visuals and details of the GLSL code above.

## ⚽Bouncing Ball

[capture (1).webm](https://github.com/user-attachments/assets/a57c6639-2f5e-445c-9342-defba4e6100b)

This was the first shader where I used ray marching along with SDFs to create a shape and a plane. I then used lighting (Lambert and Specular) and shadow boxing for the first time to add depth.

I used typical math equations to animate the movement of the ball, along with the squish/squash while preserving its volume.

## 🌟3D Stars in the Sky

[capture (2).webm](https://github.com/user-attachments/assets/d98548c9-a23e-497a-9771-c0f86a6049c8)

I used modular arithmetic and vector algebra to create a space with twinkling stars and big yellow stars that randomly move and grow/shrink.
